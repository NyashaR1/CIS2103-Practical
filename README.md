# My Profile & Mini-Portfolio
A semantic HTML5 profile and mini-portifolio webpage created for the Web Technologies course.

## About the Project
This project is a personal profile and mini-portfolio webpage created using semantic HTML5. The page contains information about me, my interests and skills, portifolio content, and a Contact Me form.

## Responsive Notes

### Breakpoints Tested
- Mobile: 375px
- Tablet: 768px
- Desktop: 1280px

### Flexbox
Flexbox is used in the navigation menu to center the links, add spacing between them, align items, and allow the links to wrap on smaller screens.

### CSS Grid
CSS Grid is used in the Skills section to display skills in separate boxes. The grid adjusts the number of columns to suit the available screen width.

### Tailwind CSS
Tailwind utility classes are used in the header and Contact section. Responsive utility classes, including `md:`, help adjust the layout on medium-sized screens and larger.

### CSS and Tailwind Split
The external `style.css` file controls the main colours, typography, spacing, navigation, skills grid, and responsive media queries. Tailwind CSS provides additional utility classes for selected sections.
